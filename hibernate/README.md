# Hibernate

<badge>Planned</badge>

This track will apply ORM concepts using Hibernate and inspect the SQL it generates.

## Planned topics

- Hibernate setup and configuration
- Entity mapping and identifiers
- Persistence context, dirty checking, and flushing
- Owning side and inverse side of relationships
- One-to-one, one-to-many, and many-to-many mappings
- Fetch types, N+1 queries, and fetch strategies
- JPQL and native SQL
- Cascades and orphan removal
- Transactions and connection management
- Caching and performance diagnostics

## Practical direction

Examples will use the shared booking domain where appropriate. Each important mapping will be paired with the relevant database schema and generated SQL so the relationship between Java objects and database rows stays visible.

Examples will be added after the ORM fundamentals track.
