# ORM Fundamentals

**Status: Planned**

This track will explain the ideas behind Object-Relational Mapping before introducing Hibernate-specific behavior.

## Planned topics

- The object-relational impedance mismatch
- Mapping objects to tables and rows
- Entity identity and primary keys
- Persistence context and identity map
- Entity lifecycle: transient, managed, detached, and removed
- Dirty checking and flushing
- Lazy and eager loading concepts

## Practical direction

We will compare the SQL and object state before and after persistence operations. The aim is to understand the behavior an ORM manages—not to memorize annotations.

Examples will be added after the concepts have been studied and verified.
