# SQL & Databases

This track contains the SQL and relational database knowledge needed to understand what JDBC and ORM code actually do.

## Topics

- Tables, rows, columns, primary keys, and foreign keys
- Data types, NULL, constraints, and defaults
- SELECT, filtering, sorting, and pagination
- INSERT, UPDATE, and DELETE
- INNER, LEFT, and RIGHT JOINs
- One-to-many and many-to-many relationships
- Indexes and query plans
- Transactions and isolation fundamentals

## Practical approach

Use the MariaDB database started by the [root setup](../README.md). Keep queries in small, focused SQL files and include the schema or sample data needed to reproduce each example.
